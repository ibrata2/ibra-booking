# حجوزات IBRA — IBRA BOOKING

**مدير حجوزات ومواعيد شخصي** لمن يعمل بشكل فردي في الفواتح ومجالس العزاء والمواليد والأفراح والمجالس الدينية.
يعمل بالكامل **دون إنترنت**، بواجهة زجاجية عصرية، عربي افتراضياً مع دعم كامل للإنكليزية.

Android • iOS — Flutter / Dart — SQLite — Riverpod — Clean Architecture — Material 3

الإصدار 1.0.0 — برمجة وتطوير **ابراهيم الخزرجي**

## نسختان من نفس المشروع

| النسخة | الاسم | لمن | البناء |
|---|---|---|---|
| events (الافتراضية) | **حجوزات IBRA** — IBRA BOOKING | الملا والقارئ الحسيني والعاملون في الفواتح والعزاء والمواليد والأفراح | `flutter build apk` |
| general | **الحجوزات IBRA** — IBRA Bookings | أي شخص لديه عمل ومواعيد: عملاء، اجتماعات، زيارات، جلسات، توصيل | `flutter build apk --dart-define=EDITION=general` |

النسخة العامة لها معرّف تطبيق مختلف (`com.ibraprogram.ibra_bookings`) فتُثبت بجانب الأولى، وأنواع مواعيدها الافتراضية: موعد عمل، اجتماع، زيارة عميل، جلسة/خدمة، توصيل/مشوار، مناسبة، شخصي، أخرى — وتسمي الزبائن «العملاء». لأيقونة مختلفة لها ضع `assets/icon/source_general.png`.

## المميزات

| القسم | ما يقدمه |
|---|---|
| **الرئيسية** | الساعة بنظام 12 ساعة، التاريخ واليوم، عدد حجوزات اليوم/الغد/الشهر، الحجز الجاري مع شريط تقدم وعداد لانتهائه، الحجز القادم مع عداد لبدايته، أجور اليوم والشهر، قائمة حجوزات اليوم |
| **إضافة حجز** | كل الحقول المطلوبة (الزبون، الهاتفان، نوع المناسبة، المكان، المحافظة، المنطقة، العنوان، أقرب نقطة دالة، رابط الموقع مع استخراج الإحداثيات تلقائياً، التاريخ، البداية والنهاية، الأجر، العربون، المتبقي، الملاحظات، الصور والمرفقات، تنبيهات وصوت خاص بالحجز، التكرار). تعديل، حذف، نسخ |
| **نظام الوقت** | 12 ساعة حصراً في كل مكان: `09:00 صباحاً` — `12:00 ظهراً` — `12:00 منتصف الليل`. دعم الحجوزات بعد منتصف الليل |
| **التنبيهات** | مستقلة لكل حجز: قبل البداية، عند البداية، قبل النهاية، عند النهاية، والحجز التالي أثناء الحجز الجاري. **رنين مستمر حتى الاستلام** + منبه بملء الشاشة + إعادة التنبيه + تأجيل + إجراءات سريعة (اتصال، موقع، مكتمل) |
| **الأصوات** | 5 أصوات مدمجة أصلية + استيراد MP3/WAV/M4A/AAC + تسجيل من الميكروفون + قص وتحديد الجزء + معاينة + تسمية وحذف + صوت لكل نوع تنبيه أو لحجز محدد + اهتزاز |
| **التقويم** | يومي، أسبوعي، شهري، سنوي، وقائمة بألوان أنواع المناسبات. **سحب وإفلات** لتغيير الموعد مع التأكيد وفحص التعارض، بحث وتنقل سريع |
| **منع التعارض** | تحذير بتفاصيل الحجز المتداخل، وتنبيه عند عدم كفاية وقت التنقل (15/30/60 دقيقة…) |
| **حالات الحجز** | مؤكد، بانتظار التأكيد، قادم، جارٍ الآن، مكتمل، ملغى، مؤجل، لم يتم الحضور — تحديث زمني تلقائي ويدوي |
| **الزبائن** | سجل تلقائي لكل زبون: عدد الحجوزات، السابقة والقادمة، إجمالي الأجور والمتبقي، اتصال وواتساب، استيراد من جهات الاتصال |
| **الحسابات** | يومي/أسبوعي/شهري/سنوي/فترة مخصصة، مدفوع وغير مدفوع، دفعات، مصروفات التنقل، رسم بياني، تصدير **PDF** و **Excel** — قابل للإخفاء |
| **التكرار** | يومياً (فاتحة 3 أيام)، أسبوعياً، شهرياً، سنوياً، أيام محددة، فترة مخصصة — تعديل حجز واحد أو كل السلسلة |
| **الخرائط** | Google أو Apple، ملاحة مباشرة، مشاركة العنوان، دون طلب إذن الموقع |
| **النسخ الاحتياطي** | تصدير/استيراد ملف واحد يشمل الحجوزات والأصوات والمرفقات + نسخة تلقائية يومية |
| **الأمان** | قفل PIN، بصمة، Face ID، لا يرسل أي بيانات لأي خادم |

## البناء

لا تحتاج تثبيت أي شيء على حاسبتك: ارفع المشروع إلى GitHub وستبني **GitHub Actions** تلقائياً:

- `IBRA-BOOKING-1.0.0-android-universal.apk` — للتثبيت المباشر على أي أندرويد
- `IBRA-BOOKING-1.0.0-android-arm64.apk` — أصغر حجماً للأجهزة الحديثة
- `IBRA-BOOKING-1.0.0-android.aab` — للنشر على Google Play
- `IBRA-BOOKING-1.0.0-ios-unsigned.ipa` — للآيفون (يحتاج توقيع)
- `IBRA-BOOKING-1.0.0-ios-xcode-project.zip` — مشروع Xcode كامل

التفاصيل في [docs/BUILD.md](docs/BUILD.md).

## الهيكل

```
lib/
  domain/        الكيانات + منطق الجدولة والتعارض والتكرار (Dart نقي، مختبر)
  data/          SQLite + المستودعات
  application/   حالات الاستخدام (حفظ، حذف، نقل، إعادة جدولة)
  services/      الإشعارات، الأصوات، النسخ الاحتياطي، التصدير، الخرائط
  presentation/  الشاشات والودجات (Riverpod)
  core/          الترجمة، الوقت 12 ساعة، الثيم الزجاجي، ZIP/Excel/PDF، SHA-256
packages/ibra_native/   تكاملات أصلية Kotlin + Swift (تحويل/قص الأصوات، MediaStore، المعاينة)
platform/               إعدادات Android/iOS (الصلاحيات، المستقبلات، الشاشة الافتتاحية)
tool/                   setup_platforms.py + generate_icons.py
```
